# Odoo Property Management  An Odoo 17 addon for managing property records and related owners.  ## Features 
- Manage properties, owners, tags, and building records.
- Track property status, prices, and property details with Odoo models and views.
- Generate a QWeb PDF property report.
- Add scheduled checks for past expected selling dates.
- Extend Odoo contact and accounting views with property references.

## Built with

- Odoo 17
- Python
- Odoo ORM
- XML views and QWeb reports

## Installation

1. Copy this addon folder into an Odoo `custom_addons` directory.
2. Add that directory to the Odoo `addons_path` configuration.
3. Restart Odoo, update the Apps list, and install the addon.

## Notes

This repository contains the addon only; it does not include the Odoo server source or a database.
